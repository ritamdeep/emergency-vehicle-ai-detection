# Model Training & Evaluation

This directory contains scripts and curated diagnostic results for model training and validation.
- `train.py`: Fine-tuning script for YOLO emergency vehicle detection
- `val.py`: Validation script computing precision, recall, and mAP metrics
- `merge_dataset.py`: Utility for merging Indian traffic datasets
- `results/`: Curated training run outputs (F1/PR curves, confusion matrices, and validation predictions)
